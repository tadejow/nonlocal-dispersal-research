# Symmetrical Kernel Spectrum Manuscript

This directory contains the LaTeX source and figures for the manuscript analyzing the spectral gap, properties of principal eigenvalues, and eigenfunction regularity for the non-local Neumann dispersal operator with symmetric kernels.

## Compilation

You can compile the manuscript using standard LaTeX compilers (e.g., pdflatex).

> pdflatex main.tex
> bibtex main
> pdflatex main.tex
> pdflatex main.tex
